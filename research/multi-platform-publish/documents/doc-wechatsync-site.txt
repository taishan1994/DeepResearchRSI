常见问题

基础问题

插件收费吗？

完全免费且开源！如果觉得好用，欢迎到
Chrome 商店
留个好评，或到
GitHub
点个 Star。

我的账号密码安全吗？

插件不会获取任何密码。它使用你浏览器中已有的登录 Cookie，所有数据存储在本地，不经过任何第三方服务器。

同步后的文章在哪里？

文章同步后保存在各平台的「草稿箱」中，登录对应平台后台即可查看、修改和发布。

为什么平台显示未登录？

请确认是在浏览器网页端登录（不是手机 App），登录后刷新页面或等待约 1 分钟插件即可检测到。

支持哪些浏览器？

Chrome、Edge、360 浏览器、QQ 浏览器等所有 Chromium 内核浏览器均可使用。

和微小宝、新媒体管家有什么区别？

文章同步助手完全开源免费，无需付费订阅，代码透明可审计，数据本地存储更安全，且支持 AI 写作 MCP 集成。

支持 AI 写作工具发布文章吗？

支持。通过 Anthropic MCP 协议，配合 Claude Desktop 或 Claude Code 使用，用 AI 写文章后一键同步到多个平台。

使用 & 排错

同步后排版乱了怎么办？

建议使用通用排版格式。微信公众号排版较为灵活，部分样式在其他平台可能不被支持，同步后检查草稿并微调即可。

什么是浏览器插件？

浏览器插件是安装在 Chrome 等浏览器中的小工具，安装后在浏览器右上角出现图标，点击即可使用。

为什么需要登录各平台？

插件使用你浏览器中已有的登录状态来发布文章。在浏览器中正常登录各平台后，插件即可自动检测到。

同步到头条总是失败？

请尝试重新登录头条号，并确保已完成实名认证。

支持同步音频、视频吗？

目前仅支持文字和图片的同步，音频和视频暂不支持（大多数平台也不支持跨平台上传音视频）。

如何把公众号文章同步到知乎/头条？

先在浏览器中登录知乎和头条，然后打开微信公众号文章页面，点击插件图标，选择目标平台，文章会同步到草稿箱。
