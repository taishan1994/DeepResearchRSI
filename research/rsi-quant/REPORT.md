# rsi-quant 调研报告（过程记录）

> 这是一个**执行记录**，不是论文。论文在 [`paper/PAPER.md`](./paper/PAPER.md) 与
> [`paper/latex/main.pdf`](./paper/latex/main.pdf)。本文件记录：为什么这么问、
> 检索与筛选怎么做的、哪些判断被推翻了、以及还有什么没解决。

## 0　这次调研的由来

站内已有三篇相邻归档，都不覆盖量化：

| 归档 | 对象 | 判据 |
|---|---|---|
| [`rsi-inference`](../rsi-inference/REPORT.md) | 一段 GPU 程序 | 一个数（稳健计时） |
| [`rsi-serving`](../rsi-serving/REPORT.md) | 整条推理链路 | 一组统计量（配对下界、SLO） |
| [`rsi-model-training`](../rsi-model-training/REPORT.md) | 训练过程 | 外部锚点上的分数 |
| **本篇** | **权重与激活的数值表示** | **前沿位置 + 退化阈值** |

量化有一个前几篇都没有的性质：**「更省」与「更准」是一对连续可调的权衡。**
改一个 kernel 要么快要么慢；改一个 bit 数则是沿着一条前沿滑动。
这决定了量化的判据不能只是一个阈值，还得说明这个阈值所在的位置。

## 1　问题怎么收敛的

### 1.1　初始问题太宽

初始问题是「模型量化的 RSI 进展如何」。这个问题无法回答，因为：

- 「量化」跨了权重 / 激活 / KV cache / 优化器状态四个不同的东西；
- 「RSI」在语料里指三种东西：自动位分配、agent 流水线、以及评测协议本身的演化。

### 1.2　改成「压到多少才算还正确」

于是把问题改成一句可检验的话：

> 量化层的 RSI 卡在**判据的不可迁移性**上，而不是搜索能力上。

若成立，则创新应集中在校准集构造、评测划分、阈值推导与代理标定，而不是位分配算法。

## 2　检索与筛选

### 2.1　检索

七组检索式、26 条式子、时间下限 2025-01-01，走 arXiv 官方 API（`fetch_quant.py`）：

| 组 | 关注 |
|---|---|
| A | 位宽 / 混合精度的自动分配 |
| B | agent 直接参与量化决策 |
| C | 演化 / RL 驱动的量化策略搜索 |
| D | KV cache / 激活量化 |
| E | QAT 与量化感知的自动配方 |
| F | 判据：量化到底怎么算「无损」 |
| G | 循环本身与失效模式（旁证） |

去重后 **1358 篇**候选（2025 年 302、2026 年 1056）。

### 2.2　筛选

先按标题是否含量化词硬筛（411 篇），再按「是否给出一个能被另一个系统拿去当判据的量」划分：

- **core 17 篇**：分配（TileQuant / 量化损伤结构 / 层位宽分配 / Q-Strata / 误差归因 / MultiAlloc / AlignQuant）、
  敏感度代理（MXSens / 谱平坦探针 / CASA / FAMPWQ）、
  agent 流水线（APQF / Q-PACE / QATFactory / CompressionBench）、
  无校准（ReRound / CAT-Q）
- **旁证 17 篇**：保真度指标与审计（Accuracy is Not Enough / Displacement Is Not Direction 等）、
  跨对象一致性（同一位宽不同结果 / QuantiBias / 逐字记忆 / 能耗 / 显存稳定性）、QAT 综述

⚠️ 一个判断需要说明：**把「敏感度/归因」算进 core。** 量化的循环与传统自动优化不同，
它的瓶颈不是「搜不动」，而是「不知道往哪搜」。一个能给出 per-layer 敏感度的估计器，
实际上就是循环里的 cost model。若只收「完整 agent 系统」，这一层会只剩两三篇。

## 3　主张怎么来的，哪些被删了

### 3.1　两轮收敛

第一轮 6 条（对象 / 无损定义 / 分数不动 / 指标方向 / 全局 vs 局部 / 代理标定），
第二轮 6 条（校准集 / agent 流水线 / 局部与整体 / 跨对象边界 / 代价 / 可迁移判据）。

每条主张至少 3 条证据、至少 1 条 primary supports（C1），共 **64 条证据**。

### 3.2　一个被推翻的假设

初稿里我写的是「先找关键层，再把精度补给它」——这是量化领域的默认直觉。

**这条被直接否证了。** 有一篇工作在同等预算下做了干净对照：同样是 +0.146 bit/weight，
全局细化粒度对所有测试模型都赢局部修补[c-budget-global]。

于是我把它反向写成了第 5 章的主结论，并且进一步追问：如果「关键层」不是强信号，
那敏感度代理还有什么用？答案在第 5.2 节：代理的用处不是「找关键层」，
而是「在同一粒度内排序」——而这就必须被标定（0.83 可用，−0.07 不可用，0.25 勉强）。

### 3.3　被删掉的东西

初版想把「量化前沿」画成一张图（不同 bit 宽度下的 perplexity 曲线）。**没画成，也不该画。**

理由：那需要跨论文拼接数值，而每篇的模型、校准集、评测集都不同。
按 P2（数值可回溯）的规矩，这种图必然要么编数、要么违规。

最终四张图全部是**同一篇论文内部的对照**：一次性解 vs 循环解（同一模型）、
代理相关性（同一实验）、局部排序推翻率（同一实验）、路径分歧率（同一模型两个精度）。

### 3.4　被降级的东西

「敏感度代理必须被标定」这条结论，只找到一篇工作给出直接的相关性数字。
其余是间接支持（标量代理失效的下界证明、条件数指示器）。
故这条在 `run.json` 里被标注为「本文最脆的一条」。

### 4.1　一个必须记下的教训：量化论文的全文快照有大量目录残渣

LaTeXML 会把网页导航（"Report Issue Back to Abstract"、"Contents Reading mode"）
混进正文。手抄 quote 时极易抄到目录行而不是正文——初期的几次探测就撞上了。

处理办法：先用 `digest.txt` 目视定位，再用 `resolve()` 回填原文子串。
本轮 64 条 quote 一次通过 E1，靠的是这个流程而不是运气。

## 5　没解决的事

1. **2 篇只有摘要**（2607.09999、2610.09877），其证据未在全文核对到。
2. **纳入集是人工判断**：17 core + 17 旁证的取舍没有被任何校验器覆盖。
3. **没有自跑实验**：全部数字二手。
4. **「代理必须被标定」证据偏薄**：只有一篇直接给出相关性数字。
5. **没有正面回答「RSI 什么时候会加速」**：量化的回报曲线在语料里同样只报终点值。
