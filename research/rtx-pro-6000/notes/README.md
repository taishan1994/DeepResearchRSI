# notes/ — 过程笔记

本目录存放研究过程中的**原始材料与中间产物**，不属于最终交付物。

## 放什么

- **原始摘录**：网页正文、PDF 抽出的文字，按来源 ID 命名（如 `src-ansys-gpu.txt`）
- **待验证线索**：尚未归档进 `sources.csv` 的候选来源清单
- **计算草稿**：从实测数据推导派生指标的过程（如「同源比值」「每美元成本」）
- **排查记录**：访问失败、反爬、超时的具体现象，供后来者复用

## 不放什么

- **不放 `sources.csv` / `evidence.csv` / `claims.csv` 的内容** —— 那些是结构化留档，是交付物
- **不放已写入 `REPORT.md` 的成文内容**
- **不放二进制大文件**（PDF 原件等），只放抽出的文本

## 为什么保留这个目录

`REPORT.md` 是**结论**，本目录是**得出结论的路径**。当某个数字在半年后受到质疑时，`notes/` 里的原始摘录是唯一能自证的材料。

> 命名约定：与 `sources.csv` 的 `source_id` 保持一致，便于双向定位。
