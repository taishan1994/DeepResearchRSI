# services/evidence

从文档中抽取可引用的证据，并把它们组织成可审计的主张。

## 职责

- `Evidence` 抽取：定位精确片段 + locator
- `Claim` 构建：把证据组合成原子主张
- 来源匹配：判断片段对主张是 `supports` / `refutes` / `context`
- 冲突图：同一主张的多个证据方向不一致时建边
- 关系抽取：论文/方法/数据集之间的提出、改进、复现、比较、替代

## 关键不变量

- **E1**：`quote` 必须是原文子串。允许截断，不允许改写或翻译后回填。
- **C1**：`confidence=high` 要求至少一条 `trust_tier=primary` 的 `supports` 证据。
- **C2**：系统推断不得写成来源事实；必须填 `derivation` 并在报告中标注。
- **C3**：冲突主张并列呈现，不强裁决（见 ADR-0003）。

## 抽取质量要求

片段定位准确率是本模块的核心指标。一个"看起来对但引错了段落"的引用，比没有引用更糟。
