# services/research

研究流程的主体：规划、检索、分析、综合、核验。

## 角色

| 角色 | 职责 |
|---|---|
| **Planner** | 解析 brief、管理问题树、分配预算 |
| **Search workers** | 按来源类型或子问题并行检索，只读、限速 |
| **Evidence analyst** | 抽取主张、方法、结果、局限与关系 |
| **Synthesizer** | 形成主题级综合与报告 |
| **Verifier / critic** | 核验引用、时效性、覆盖度、反例 |

## 设计要点

- **动态规划**：先生成问题树与初始查询，再依证据补充/合并/裁剪子问题。不写死计划。
- **缺口驱动补搜**：先审计证据缺口，再花预算，而不是按固定计划烧预算。
- **并行 worker 返回结构化记录**（证据 + 查询记录 + 未解决点），不各自写完整报告。
- **综合按问题树写**，不按来源逐篇摘要。

## 核验清单

报告拆成原子主张后逐条检查：

- [ ] 引用是否真实存在
- [ ] 来源是否**直接支持**该主张（而非仅相关）
- [ ] 数字、日期、方法名、版本是否与原文一致
- [ ] 是否把作者自述当成独立验证
- [ ] 是否存在反证、不同定义或不同实验设置
- [ ] "最新"是否有明确截止时间
- [ ] 是否漏掉新版本、撤稿或更正
