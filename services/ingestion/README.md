# services/ingestion

把"抓到的原始内容"变成"可引用的结构化文档"。

## 职责

- 下载与快照保存（HTML / PDF 原文留档）
- 解析（HTML → 文本 + 章节结构；PDF → 文本 + 页码）
- 分段（保留 section/page 锚点，供 `Evidence.locator` 使用）
- 去重（按内容哈希，跨来源、跨版本）
- 版本化（内容变化生成新 `Document`，不覆盖旧的）

## 关键不变量

- **D1**：`content_hash` 变化即视为新版本。
- **D2**：学术元数据与网页正文分开存储，便于纠错和重新解析。
- 每份文档记录 `parser_version`，保证解析结果可重放。

## 已知难点

| 难点 | 现状 |
|---|---|
| JS 渲染的 SPA | 静态抓取只能拿到空壳，需记录 `access=blocked` 并降级 |
| Cloudflare 反爬 | 记录为 `access=blocked`，不尝试绕过 |
| PDF 解析 | 需保留页码锚点，否则引用无法定位 |
| 编码错误页面 | 需检测乱码并标记解析失败，而不是喂给抽取器 |
