# apps/web

研究报告浏览与审计界面。

## 核心视图

| 视图 | 作用 |
|---|---|
| 报告阅读 | 渲染 Markdown，`[c-*]` 标注可点击展开证据 |
| 证据抽屉 | 显示原文片段、locator、来源 URL、抓取时间 |
| 轨迹审计 | 查询历史、来源选择理由、预算消耗、停止原因 |
| 子问题看板 | 每个子问题的 answered/partial/unanswered 状态 |
| 冲突视图 | `confidence=disputed` 的主张并列展示双方证据 |

## 设计约束

- **每个事实性结论都必须能点回原文片段**。做不到的句子不该出现在报告里。
- 冲突主张不改写为单一结论（见 `docs/adr/0003-conflict-presentation.md`）。
- 显示"信息截止时间"，不显示"实时"这类无信息量的词。
